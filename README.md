# AI 自动化测试框架

基于 Python 的大语言模型自动化测试 Demo，用于对大模型 API 进行批量测试、质量评估和报告生成。

## 🎯 项目背景

大语言模型（LLM）的输出具有**不确定性**，传统测试用例的"预期结果精确匹配"方式不再适用。本项目展示了如何通过**自动化脚本 + 统计策略**，对 AI 模型进行系统性测试。

## 🛠️ 技术栈

- Python 3.12
- Requests（API 调用）
- 正则表达式（文本清洗与匹配）
- JSON（数据交互）

## 📋 测试覆盖

| 测试维度 | 示例用例 | 检查方式 |
|---------|---------|---------|
| 基础对话能力 | "你好，请用一句话介绍自己" | 关键词 + 字数 |
| 数学推理能力 | "1+1等于几？" | 关键词 + 字数 |
| 文本生成能力 | "写一句关于深圳的诗" | 字数检查 |
| 身份识别能力 | "你的名字是什么？" | 关键词匹配 |
| 多语言响应能力 | "请用中文回答：Hello" | 关键词匹配 |
