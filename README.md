# AI 自动化测试框架

> 基于 Python 的大语言模型自动化测试 Demo，用于对大模型 API 进行批量测试、质量评估和报告生成。

---

## 🎯 项目背景

大语言模型（LLM）的输出具有不确定性，传统测试用例的“预期结果精确匹配”方式不再适用。本项目展示了如何通过自动化脚本 + 统计策略，对 AI 模型进行系统性测试。

---

## 🛠️ 技术栈

- Python 3.12
- Requests（API 调用）
- 正则表达式（文本清洗与匹配）
- JSON（数据交互）

---

## 📊 测试覆盖

| 测试维度 | 示例用例 | 检查方式 |
|---------|---------|----------|
| 基础对话能力 | “你好，请用一句话介绍自己” | 关键词 + 字数 |
| 数学推理能力 | “1+1 等于几？” | 关键词 + 字数 |
| 文本生成能力 | “写一句关于深圳的诗” | 字数检查 |
| 身份识别能力 | “你的名字是什么？” | 关键词匹配 |
| 多语言响应能力 | “请用中文回答：Hello” | 关键词匹配 |

## 🚀 快速开始

### 1. 克隆项目

```bash
git clone https://github.com/Jun-Menthol/ai-test-demo.git
cd ai-test-demo
```

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

### 3. 配置环境变量

创建 `.env` 文件，添加你的 API Key：

```
DEEPSEEK_API_KEY=你的密钥
```

### 4. 运行测试

```bash
python test_runner.py
```

### 5. 查看测试报告

运行后会在 `reports/` 目录下生成 JSON 格式的测试报告。

## 📁 项目结构

```
├── test_cases.json       # 测试用例配置
├── test_runner.py        # 测试执行主程序
├── evaluator.py          # 评估逻辑（关键词、字数、正则）
├── utils.py              # 工具函数
├── reports/              # 测试报告输出目录
└── requirements.txt      # 依赖清单
```

## 📊 测试结果示例

| 测试用例 | 预期结果 | 实际结果 | 通过 |
|---------|---------|---------|------|
| “你好，请用一句话介绍自己” | 包含“助手”等关键词，字数 5-20 字 | “我是AI助手，很高兴为你服务。” | ✅ |
